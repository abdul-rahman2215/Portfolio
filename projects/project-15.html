AI Chatbot Interface

Conversational UI that interfaces with a Large Language Model API.

View Live Demo View Source Code

Overview

A modern, ChatGPT-style conversational interface that connects to an external Large Language Model API. It provides a sleek wrapper for interacting with AI, designed with user experience and prompt context management in mind.

The application maintains conversation history, allows users to select different "personalities" or system prompts for the AI, and renders code snippets returned by the AI with proper formatting and copy-to-clipboard functionality.

Key Features

  • Streamed API responses for a fast, typewriter-like feel.
  • Conversation history management (clear, save, export).
  • Markdown and code syntax highlighting in chat bubbles.
  • System prompt customization.
  • Responsive design optimized for both desktop and mobile typing.

Challenges & Learnings

Handling Server-Sent Events (SSE) to stream the AI's response chunk-by-chunk to the UI was a fantastic learning opportunity. I gained deep knowledge of the Fetch API's readable streams and how to continuously update the DOM without causing jitter or layout shifts.

Tech Stack

SvelteKit Tailwind CSS OpenAI API Markdown-it

My Role

  • Engineered the streaming API consumption logic.
  • Designed and built the chat UI components.
  • Implemented the markdown rendering pipeline for AI responses.
