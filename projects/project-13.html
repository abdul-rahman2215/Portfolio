Markdown Note-Taking App

Browser-based note application with live markdown preview and cloud sync.

View Live Demo View Source Code

Overview

A minimalist, distraction-free writing environment built for developers and technical writers. It offers a split-pane view where users can write Markdown on the left and see the rendered HTML in real-time on the right.

The application supports complex markdown syntax including tables, code blocks with syntax highlighting, and inline HTML. Notes are automatically saved to the browser and can be synced to a remote database.

Key Features

  • Real-time Markdown to HTML compilation.
  • Syntax highlighting for over 30 programming languages.
  • Folder organization and tagging system for notes.
  • Auto-save functionality to prevent data loss.
  • Export notes as PDF or raw Markdown files.

Challenges & Learnings

Parsing Markdown in real-time without causing input lag required performance optimization. I learned how to use web workers to offload the heavy parsing tasks from the main thread, ensuring the editor remained buttery smooth even when dealing with very large documents.

Tech Stack

My Role
