URL Shortener Tool

Compact shareable links with click analytics, custom slugs, QR code generation, and a Redis caching layer for sub-10ms redirect latency.

🔗
Overview

What is this project?

A full-stack web service comparable to Bitly or TinyURL. It accepts long, unwieldy URLs and generates compact aliases that redirect instantly to the original destination — built for speed and capable of handling high concurrent traffic volumes.

Beyond simple redirection, every shortened link gets its own analytics dashboard showing total clicks, unique visitors, geographic breakdown, device types (mobile vs. desktop), and referrer sources — all updated in real-time.

The service exposes a RESTful API for programmatic link generation, making it useful as a backend utility for other applications, not just a standalone product. Developers can generate thousands of short links via API and track each one independently.

Key Features

What it can do

  • Base62 URL encoding to generate collision-free unique short hash aliases
  • Custom slug creation — define your own alias (e.g. mysite.com/launch-day)
  • Per-link analytics: total clicks, unique visitors, top countries, and device breakdown
  • Automatic QR code generation for every shortened URL — great for offline use
  • Redis caching layer delivering sub-10ms redirect latency even under high load
  • REST API with API key authentication for programmatic and bulk link creation

⚡ Challenges & Learnings

Ensuring ultra-low redirect latency was the primary engineering challenge. Without caching, each redirect required a MongoDB lookup (~40ms). Adding Redis in front of the database reduced this to ~3ms — a 13× improvement. I also had to carefully design the cache invalidation strategy to avoid serving stale redirects when links were updated or deleted.
