Portfolio Analytics Dashboard

Enterprise-grade data visualisation dashboard with custom D3.js charts and real-time RxJS streams

Live Demo View Source
📊
Overview

About the Project

An enterprise-grade analytics dashboard designed to monitor web traffic, user engagement, and sales metrics in real-time. This tool translates complex datasets into easily digestible visual summaries for business stakeholders.

The dashboard is built with Angular's component architecture for maximum scalability. Every chart is a standalone, reusable component that accepts typed data inputs — making it trivial to add new visualisations without touching existing code.

Data updates stream in via WebSocket simulation using RxJS observables, creating a live, breathing dashboard that reflects the latest numbers without a single page refresh.

Features

Key Capabilities

  • Custom interactive SVG charts built from scratch with D3.js (line, bar, donut, heatmap)
  • Data filtering by custom date ranges, regions, and user segments
  • Real-time metric updates simulated via RxJS observable streams
  • Exportable PDF and CSV reports with a single button click
  • Fully typed TypeScript codebase with strict mode enabled
  • Accessible keyboard-navigable chart interactions with ARIA labels
Responsibilities

My Role

  • Architected the Angular application module structure and component library
  • Created all five custom D3.js chart components with full TypeScript typing
  • Implemented the reactive data stream architecture using RxJS observables

Tech Stack

Angular 17 TypeScript D3.js RxJS SCSS
Engineering Challenge

Using D3.js (imperative DOM manipulation) within Angular (declarative change detection) without triggering unwanted re-renders required careful architecture. I wrapped all D3 code inside ngAfterViewInit and used NgZone.runOutsideAngular() to prevent D3's internal timers from flooding Angular's change detection cycle.
