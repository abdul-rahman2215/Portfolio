Fitness & Habit Tracker

Mobile-first web app to log workouts and monitor progress over time.

View Live Demo View Source Code

Overview

A Progressive Web App (PWA) designed to help users build better habits and track their physical fitness journeys. It focuses on a frictionless, mobile-first data entry experience so users can log workouts while at the gym without distraction.

The app gamifies the experience by visualizing "streaks" and providing weekly summary reports of volume lifted, miles run, and habits completed.

Key Features

  • Progressive Web App support (installable on iOS/Android home screens).
  • Offline mode support using Service Workers.
  • Customizable workout routines and exercise databases.
  • Visual habit streaks (similar to GitHub contribution graphs).
  • Cloud synchronization across multiple devices.

Challenges & Learnings

Implementing reliable offline functionality was the core challenge. I learned how to effectively configure Service Workers for caching app shells and intercepting API requests to queue data locally using IndexedDB when the device loses network connectivity.

Tech Stack

React Redux Toolkit Firebase Auth/Firestore Workbox (PWA)

My Role

  • Built the mobile-first, responsive interface.
  • Implemented offline data synchronization strategies.
  • Designed the gamification elements and charting components.
