Custom Music Player

Web audio player supporting playlists, shuffle, and custom audio controls.

View Live Demo View Source Code

Overview

A beautifully designed, custom web audio player that steps away from the default browser audio controls. It features a neumorphic design aesthetic that looks like physical hardware.

The app allows users to load local audio files, manage custom playlists, and control playback (play, pause, next, previous, shuffle, repeat). It also features a dynamic progress bar and volume controls.

Key Features

  • Full playback control utilizing the HTML5 Web Audio API.
  • Playlist management queue.
  • Dynamic UI that extracts colors from the current album art.
  • Visual audio equalizer.
  • Keyboard shortcuts for accessibility (Space to play/pause, arrows for skipping).

Challenges & Learnings

Dealing with browser autoplay policies and state synchronization between the UI and the underlying HTMLAudioElement was tricky. I learned how to properly manage audio contexts, track time updates efficiently using `requestAnimationFrame`, and build accessible range sliders from scratch.

Tech Stack

HTML5 Audio API Vanilla JS CSS Variables ColorThief.js

My Role

  • Designed the neumorphic interface.
  • Wrote the core audio playback and queue logic in vanilla JavaScript.
  • Implemented the album art color extraction feature.
